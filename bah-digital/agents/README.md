# AI workforce

The **AI CEO is an orchestrator**: it understands the request, plans, assigns
specialists, reviews their work and asks for approval. It does not do every job itself.

```
AI CEO
├── Research Director   → market, competitor, technology, trend scouts
├── Marketing Director  → content, SEO, social, email, ads
├── Creative Director   → script, graphic, video, brand
├── Technology Director → developer, UI/UX, database, QA, DevOps
├── Operations Director → project manager, CRM, support, admin
└── Intelligence Director → strategy, innovation, benchmark, experiments
```

Each agent is defined by a YAML file like `_template.yaml`. Built in Phase 4.
