# KDP and ebook cheat sheet (verify details on Amazon KDP help)

## Files
- Source: Markdown -> `scripts/build_ebook.sh` -> EPUB (and PDF).
- Check in **Kindle Previewer**; validate EPUB with **EPUBCheck**.

## Metadata
| Field | Tip |
|---|---|
| Title + subtitle | Title is memorable; subtitle contains searchable phrase |
| Description | Hook, 3-5 bullets, who it's for, CTA; limited HTML allowed |
| Keywords | 7 phrases buyers search; no repeats of title words |
| Categories | Most specific; request additional ones through KDP support (verify) |
| Price | $2.99-$9.99 band for 70% royalty (verify) |
| AI disclosure | Declare AI-generated content when asked (verify) |
| Cover | ~1600 x 2560 px, readable thumbnail |

## Pre-publish checklist
Table of contents links work; no placeholder text; images have alt text; consistent headings; copyright page; about the author; CTA to email list; links tested; spellcheck; fact-check; read on phone.

## Royalty sanity check
`royalty = list_price * rate - delivery_fee_per_MB * size` (70% option). Keep images compressed.

## Wide vs Select
Select = 90-day exclusivity, Kindle Unlimited. Wide = Kobo, Apple, Google, D2D, direct.

## Launch
Email list, free-chapter funnel, social excerpts, newsletter swaps, genuine reader reviews (no incentives that break rules).

## Series/reuse
Turn chapters into blog posts and lead magnets; combine 3 books into a bundle and a paperback.
