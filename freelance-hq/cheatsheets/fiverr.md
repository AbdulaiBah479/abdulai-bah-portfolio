# Fiverr cheat sheet (limits and numbers: verify in the gig editor)

| Item | Value / rule |
|---|---|
| Seller fee | 20% of order value (verify) |
| Title | "I will ..." + primary keyword first, ~80 chars max |
| Tags | 5 |
| Packages | Basic / Standard / Premium; price ratio ~1 : 2.5 : 5 |
| Description | ~1,200 chars |
| Gallery | 3 images + 1 video + PDFs (verify) |
| First 24h | Reply fast; response rate and time are ranking signals |
| Thumbnail | Big text promise, 1 face or product, high contrast, no clutter |

## Gig title formulas
- `I will build a [result] for [buyer] using [tool]`
- `I will automate your [process] with n8n and AI`
- `I will design [deliverable] that [benefit]`

## Description skeleton
1. Hook (pain + promise). 2. Who it's for. 3. What you get (bullets). 4. How it works (3 steps). 5. Why me (1 proof). 6. CTA: "Message me before ordering with ...".

## Buyer request reply (under 100 words)
Mirror their goal -> one specific idea -> one relevant proof link/sample -> price + days -> question.

## Delivery checklist
Requirements read -> kickoff message -> mid-point preview -> QA -> delivery with how-to -> review request.

## Do / Don't
Do: niche gigs, real samples, fast replies, clear extras, honest AI disclosure, keep chat in-platform.
Don't: share emails/WhatsApp to take payment off-platform, copy others' gigs, buy reviews, create second accounts, over-promise delivery times.

## Fix by symptom
Impressions low -> keywords/category. Clicks low -> thumbnail/title. Orders low -> price/proof/description. Messages but no orders -> clarify packages and add FAQ. Revisions high -> tighter requirements form.
