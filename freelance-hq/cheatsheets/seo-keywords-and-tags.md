# Keywords and tags cheat sheet

## Where to mine (free)
Marketplace search-box suggestions, "related searches", competitors' titles/tags, Google autocomplete & People Also Ask, Amazon suggestions (KDP keywords), Etsy suggestions, Pinterest search, Reddit/Quora/forums, Google Trends, YouTube suggestions.

## Pattern
`[tool/format] + [result] + [buyer/niche]`
Examples: "n8n automation for agencies", "AI chatbot for website FAQ", "notion template freelancer finances", "canva instagram templates for real estate".

## Slot map
| Slot | Rule |
|---|---|
| Title | Primary keyword first, natural wording |
| Subtitle/first line | Secondary keyword + benefit |
| Tags (Fiverr 5, Etsy 13, KDP 7 keyword boxes; verify) | Distinct long-tail phrases, no repeats |
| Category | Where buyers browse |
| Description | Keywords naturally in first 150 chars and headings |
| Images alt/file names | Descriptive |

## Scoring grid
Relevance 5/5 required | Demand signal | Competition (strong sellers?) | Your price fit.

## Avoid
Stuffing, misleading terms, competitor trademarks, irrelevant trending terms, duplicates.

## Iterate
Change one element per 2 weeks; track impressions -> clicks -> orders.
