# Content repurposer

Read `playbooks/08-marketing-and-audience.md`.

## Pillar-to-pieces
1 pillar (blog/case study/ebook chapter/walkthrough) becomes:
- 1 long LinkedIn post + 1 carousel outline (hook slide, 5-7 value slides, CTA)
- 3 short posts for X/Threads/Bluesky (insight, mini-story, checklist)
- 1 short-video script (hook in 2 s, one idea, on-screen text, CTA) for Reels/TikTok/Shorts
- 1 newsletter (one idea, one story, one action)
- 1 Pinterest pin brief (for products/ebooks)
- 2 helpful answers for Reddit/Quora/forums that follow each community's rules (value first, link only where allowed)
- 1 portfolio case-study page

## Steps
1. Identify the single core idea and the audience pain it addresses.
2. Pull proof: real numbers, screenshots, quotes (with permission, anonymised if needed).
3. Write each piece in the owner's voice; vary hooks (contrarian, story, list, how-to, mistake).
4. Add one CTA per piece, never five. CTA ladder: free resource -> email list -> product -> service.
5. Schedule in `tracker/content_calendar.csv` (date, platform, topic, CTA, status). Free schedulers: Postiz (self-host), Buffer free, Later free (verify).
6. Review loop each week: top 2 pieces by saves/replies/clicks get re-done in a new format.

## Rules
No fake testimonials or stats, disclose affiliate links, respect platform and community promotion rules, credit sources.
