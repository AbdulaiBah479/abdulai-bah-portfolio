# Portfolio case study

## Structure (500-800 words + visuals)
1. **Title with result:** "How an AI FAQ bot cut repeated questions for a clinic" (only if true).
2. **Client/context** (anonymize if needed) and **problem** with real numbers if available.
3. **Goal and constraints** (time, budget, tools).
4. **What I did:** 4-6 steps, with screenshots/diagrams; tech stack; decisions and trade-offs.
5. **Result:** metrics, before/after, quotes (with permission). If no numbers exist, state qualitative outcomes honestly or mark `TODO(owner)` to collect them.
6. **What I learned / what I'd improve.**
7. **CTA:** "Need something similar? Message me."

## Sources
For the owner's existing projects, read `../index.html` and `../bah-digital/`. Ask the owner for facts you cannot see; never invent metrics, client names or quotes.

## Outputs
- `clients/_self/case-studies/<slug>.md`
- A short version for Fiverr/Upwork portfolio items (title, 2-sentence summary, 3 images brief).
- A LinkedIn post version via `content-repurposer`.
- If asked, an HTML section for `../index.html`, matching existing styles in `../style.css`; show the diff and let the owner approve before editing the live portfolio.

## Rules
Honest, permissioned, no confidential data, no copyrighted visuals, accessible alt text.
