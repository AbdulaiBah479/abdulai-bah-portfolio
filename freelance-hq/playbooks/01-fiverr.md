# 01. Fiverr playbook

> Numbers marked `(verify)` change; confirm on Fiverr's help centre before relying on them.

## How Fiverr works
Buyers search -> see gigs ranked by relevance + conversion + seller quality -> order. You earn from gig search, Buyer Requests (where available), repeat clients, and Fiverr Promoted Gigs (paid, optional). Fiverr takes a **20% commission** on seller earnings (verify). Payouts depend on your country's available methods (verify).

## Account setup checklist
- Real name and a clear, friendly profile photo. One account per person (multiple accounts violate TOS).
- Seller profile: headline, description (first 2 lines matter), skills, languages, education/certifications only if real, portfolio samples.
- Verify identity and payout method early (country-dependent).
- Read Fiverr Terms and Seller Code of Conduct; never take buyers off-platform to pay.

## Gig anatomy (limits verify)
| Part | Rule of thumb |
|---|---|
| Title | "I will ..." + primary keyword early + outcome; up to 80 chars |
| Category/subcategory | Pick where buyers browse; wrong category kills impressions |
| Tags | 5, specific buyer search phrases, no repeats |
| Packages | Basic / Standard / Premium, clearly different value |
| Description | ~1,200 chars: hook, who, what you get, process, why you, CTA |
| Gallery | 3 images + 1 video + PDFs allowed (verify), first image sells the click |
| Requirements | Questions that let you start immediately |
| FAQ | Remove objections |
| Extras | Fast delivery, revisions, source files, commercial licence |

## Ranking factors (what moves you up)
1. Click-through rate on impressions (thumbnail + title).
2. Conversion rate (price, proof, clarity).
3. Order completion, on-time delivery, response time, ratings.
4. Seller level/status.
5. Relevance of keywords to the search.
Fix in this order: thumbnail/title -> price/packages -> description -> gallery -> extras.

## First 10 sales strategy
1. Launch 2-3 narrow gigs, not 15 broad ones. Each gig = one clear buyer problem.
2. Price the Basic package low enough to win early reviews but never below your real cost; raise price after 5 reviews.
3. Use Buyer Requests daily if your account has them (verify), answer within the first hour with a custom reply.
4. Over-deliver on the first 5 orders (documentation, a short Loom-style walkthrough, bonus tweak).
5. Ask for the review after delivery in the order chat (honest, no incentives).
6. Message past buyers with a relevant follow-up offer.

## Levels (verify current criteria)
New Seller -> Level 1 -> Level 2 -> Top Rated. Criteria use completed orders, earnings, ratings, response rate, on-time delivery, and account age. Maintain by delivering on time, responding fast, avoiding cancellations, and keeping scope tight.

## Protect your account
- Never use another person's work, stock you cannot license, or AI output you cannot stand behind.
- Never share contact info or ask for off-platform payment.
- Keep response rate high; use Away mode when unavailable.
- Handle disputes calmly, offer a partial refund before a fight when the buyer's claim is partly valid.
- Do not run keyword-stuffed or misleading gigs; this triggers suppression.

## Delivery system
Intake from Requirements -> kickoff message with timeline -> milestone update -> delivery with a how-to doc -> revision window -> review request -> upsell. Templates in `templates/`.
