# 05. Account setup walkthroughs

Do these yourself; Claude cannot (and should not) create accounts for you. Screens and steps change, so follow the on-screen prompts and the platform's help pages. Items marked (verify) differ by country.

## Golden rules for ALL accounts
- Real name, real details, one account per platform. Duplicates or fake identities get permanently banned.
- Use an email you control; turn on 2FA; store passwords in a password manager (Bitwarden is free).
- Never buy, rent or borrow someone else's account.
- Read the Terms once, especially: payments must stay on-platform, no fake reviews, disclosure of AI use where required.

## Order to do things
1. Email + password manager -> 2. GitHub (portfolio backup) -> 3. Payout method (so you can actually be paid) -> 4. Fiverr -> 5. Upwork -> 6. Canva (free is enough to start) -> 7. Gumroad or Payhip (first product) -> 8. Amazon KDP (when your first ebook is ready) -> 9. Email list tool (Kit/MailerLite/Beehiiv free tiers) -> 10. LinkedIn (professional profile).

## Payout methods (check what works in YOUR country first)
Fiverr and Upwork show which withdrawal methods are available for your country in their help pages. Common options: bank transfer, PayPal, Payoneer, Wise, local options. Identity verification (ID document and sometimes address proof) is normal and required to withdraw. Ask: fees, minimum withdrawal, speed, currency conversion. Do this BEFORE you spend weeks working.

## Fiverr
1. Sign up -> "Become a Seller". 2. Fill profile: photo, description (first 2 lines matter), skills, languages. 3. Create your gig using the text Claude drafted (`/gig`). 4. Complete identity verification when asked. 5. Publish. 6. Check messages daily; use Away mode if unavailable.
Watch for: response rate, delivering on time, never taking buyers off-platform.

## Upwork
1. Sign up as a freelancer -> build the profile step by step (title, overview, skills, rate, portfolio). 2. Profiles are reviewed before activation (can take days). 3. Create a specialised profile for your niche. 4. Set saved searches and alerts for your keywords. 5. Check Connects cost on each job; send fewer, better proposals.
Watch for: fee shown per contract (0-15%, verify), scams asking to leave the platform.

## Canva
Free account is enough for thumbnails, covers, social posts. You already own Canva Pro per `../bah-digital/CLAUDE.md`. Use Brand Kit for your colours and fonts. Only use licensed elements (Canva's own library is fine within its licence terms; check restrictions for selling templates/ebooks and "Canva Pro content" rules).

## GitHub
Create an account, enable 2FA, create a private repo for client work templates and a public one for portfolio code. Public repos are proof to buyers: add clear READMEs with screenshots.

## Gumroad / Payhip (first digital product shop)
Sign up, verify identity/payout, create a product page (use `templates/product-listing.md`), upload files, set price and licence, test a purchase with a discount code of 100% (or a $0 test) to see the buyer experience. Compare fees on `cheatsheets/platform-fees-comparison.md`.

## Amazon KDP (ebooks)
Sign in with an Amazon account, complete author tax interview and payout details, create the book: title, description, keywords, categories, rights, upload EPUB and cover, set price. **Answer the AI-content question honestly** (text created by AI must be disclosed; text you wrote with AI only helping to polish/edit is "AI-assisted"; verify current wording). Preview in Kindle Previewer first.

## Email list tool
Pick one free-tier tool (Kit, MailerLite, Beehiiv; verify limits) or self-host listmonk later. Create a signup form for your lead magnet. You must have permission to email people: always include an unsubscribe link.

## LinkedIn
Use the same headline as your Fiverr/Upwork profile. Feature your 3 case studies. Post weekly (`content-repurposer`).

## Security checklist
- [ ] 2FA on email, GitHub, Fiverr, Upwork, payout tools
- [ ] Unique passwords in a manager
- [ ] Recovery codes saved offline
- [ ] Only you have access to client files
- [ ] Backup: commit trackers to your private GitHub repo daily
