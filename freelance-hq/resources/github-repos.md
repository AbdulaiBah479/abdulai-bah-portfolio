## How to use this list
1. Don't install everything. RAM budget (8 GB) and attention are the limits; add a tool only when a real task needs it.
2. Pin versions; read the licence; don't expose services to the internet without hardening.
3. Evaluate with `../bah-digital/docs/TOOL-EVALUATION.md` before adding a tool to the stack.
4. Skills and agents: copy only what you understand; review any script a skill runs before allowing it.
5. Refresh this list quarterly (`gh api -X GET search/repositories -f q='topic:claude-code-skills stars:>2000'`).
