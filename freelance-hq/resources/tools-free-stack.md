## Starter minimum (week 1)
Claude Code, VS Code, Canva, Google Drive, Wise/Payoneer (check country eligibility), Bitwarden, a spreadsheet. Add the rest only when a task demands it.

## RAM budget (8 GB)
Run at most 2 heavy services (e.g. n8n + one database). Use cloud free tiers for the rest, and local models only in the small range.
