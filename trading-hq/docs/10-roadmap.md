# 10 · Roadmap

## Days 1–30: foundations (zero real risk)
- [ ] Read 00; write your 1-page trading plan (goal, markets, risk %, limits, hours, strategy).
- [ ] Set up Python env, run tests and demo backtests; learn candles, order types, position sizing (cheatsheets).
- [ ] Open demo/paper accounts: Binance Spot Testnet, TradingView paper, MT5 demo, Alpaca paper.
- [ ] Journal every paper trade. Start monthly DCA into a broad index ETF (if you have spare cash).
- [ ] Complete Babypips basics + one investing book chapter per week.

## Days 31–90: test
- [ ] Backtest 2–3 strategies on 3+ symbols with costs; reject most.
- [ ] Paper-trade the survivor ≥ 30 days; compare to backtest expectation.
- [ ] Build dividend-growth watchlist + a bond ladder plan (`/dividend-screen`, `/bond-ladder`).
- [ ] Add alerts (Telegram/TradingView) and logging.

## Days 91–180: small live pilot (only if criteria met)
Criteria: ≥ 30 paper trades, positive after costs, drawdown within limit, plan followed 90%+ of trades.
- [ ] Fund with an amount whose total loss won't change your life; ≤ 1% risk/trade (0.25–0.5% at first).
- [ ] Spot only, API keys without withdrawal; kill-switch tested.
- [ ] Monthly review: expectancy, adherence, costs, tax records.

## Ongoing
Rebalance core annually · review strategies quarterly · retire what stops working · keep learning · never stop journaling.

## Stop-and-reassess triggers
-15% from peak · 5 consecutive rule breaks · you can't sleep · you're adding funds to "win it back."
